# Agriculture Crop Yield Analysis

## Project Description
This project analyzes crop yield and agricultural production across different Indian states using Python. It uses data analysis and visualization techniques to understand crop production patterns.

## Dataset
**Dataset Name:** Crop Yield in Indian States

**Source:** Kaggle  
https://www.kaggle.com/datasets/akshatgupta7/crop-yield-in-indian-states-dataset

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- Jupyter Notebook

## Project Objectives
- Analyze crop production and yield across Indian states.
- Identify missing values and duplicate records.
- Detect outliers in numerical columns.
- Study crop production across different seasons.
- Visualize the top states and crops by production.
- Analyze relationships between numerical variables.

## Project Tasks
1. Data collection and loading.
2. Data understanding and preprocessing.
3. Handling missing values and duplicates.
4. Outlier detection using the IQR method.
5. Exploratory Data Analysis (EDA).
6. Data visualization using charts.
7. Correlation analysis.
8. Interpretation of results and conclusion.

## Files Included
- `crop_yield_analysis.py` — Python source code.
- `crop_yield_analysis.ipynb` — Jupyter Notebook containing code and outputs.
- `PBL_Report.pdf` — Project report.
- `README.md` — Project description and instructions.

## How to Run the Project
1. Download the dataset from Kaggle.
2. Open Google Colab.
3. Upload the notebook file.
4. Upload the dataset CSV file.
5. Update the dataset file path in the code if required.
6. Run all notebook cells in order.
7. View the analysis results and visualizations.

## Expected Outcome
The project helps identify crop production patterns, seasonal differences, state-wise production, and relationships between agricultural variables.

## Conclusion
This project demonstrates how Python-based data analytics can be used to understand agricultural crop yield data and present useful observations through statistical analysis and visualizations.
